# wizard-smoke — ο πρώτος αυτόματος έλεγχος JavaScript αυτού του plugin

## Γιατί υπάρχει

Το `public/assets/ecrm-form.js` είναι το επικινδυνότερο αρχείο του project: 1.200
γραμμές που κρατούν ολόκληρη τη «νέα αίτηση», και **μηδέν** δοκιμές. Όταν η
φόρμα έγινε wizard τεσσάρων βημάτων (CHANGELOG 2026-08-20 (66)), η αλλαγή
στηριζόταν σε **μία** ιδιότητα:

> Το `collect()` διαβάζει **όλα** τα `.ecrm-input` του root, ανεξάρτητα από το αν
> φαίνονται. Τα βήματα κρύβονται με `hidden` πάνω σε wrapper — καμία τιμή δεν
> σβήνεται, κανένα πεδίο δεν φεύγει από το DOM. Άρα το σώμα του POST είναι
> **πανομοιότυπο** από όποιο βήμα κι αν πατηθεί «Αποθήκευση», και ο server, τα
> unit και τα integration tests βλέπουν ακριβώς ό,τι έβλεπαν πριν.

Αυτό δεν συμπεραίνεται διαβάζοντας. Εδώ **τρέχει** και **συγκρίνεται**: η φόρμα
συμπληρώνεται στο βήμα 3, αποθηκεύεται από τα βήματα 3, 4 και 1, και τα τρία
σώματα του POST συγκρίνονται χαρακτήρα προς χαρακτήρα.

## Πώς τρέχει

```
cd tools/wizard-smoke
npm install
npm test
```

Έξοδος `0` αν περάσουν όλα, `1` αν κάτι αποτύχει. **Δεν** είναι μέρος του
`composer check:all` και δεν μετράει σε κανέναν από τους τέσσερις αριθμούς: το
`tools/` δεν είναι στα `<file>` του `.phpcs.xml.dist` ούτε στα `paths` του
`phpstan.neon.dist`.

## Τι ΔΕΝ πιάνει — διάβασέ το πριν το εμπιστευτείς

Το `build.js` **δεν εκτελεί PHP**. Βγάζει το markup από το
`class-ecrm-shortcodes.php` αφαιρώντας τα μπλοκ `<?php ?>`, οπότε ό,τι παράγουν
οι βρόχοι και οι closures **λείπει**: τα πεδία του `$ecrm_field()` (όνομα,
επώνυμο, ΑΔΤ, διευθύνσεις…), τα chips, τα `<option>` των select. Μένουν όσα
είναι γραμμένα με το χέρι — `afm`, `term_months`, `notes`, `consent` και τα
υπόλοιπα — και ο σκελετός του wizard.

Άρα ο έλεγχος αποδεικνύει **τη λογική του wizard και την αμεταβλητότητα του
payload**, όχι ότι κάθε πεδίο της αίτησης φτάνει σωστά. Το δεύτερο το καλύπτουν
τα integration tests, από τη μεριά του server.

Δύο συνέπειες που αξίζει να ξέρεις:

* Αν αλλάξει η κεφαλή του `ecrm-form.js` (το `import`) ή τα όρια της φόρμας στο
  shortcode, το `build.js` **σταματά με μήνυμα** αντί να παράγει σιωπηλά άδειο
  αρχείο.
* Το `form.html` και το `form.js` είναι παράγωγα και δεν μπαίνουν στο git.
