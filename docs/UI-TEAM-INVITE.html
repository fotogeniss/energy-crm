Σημειώσεις για έγκριση

  • Το πεδίο «Κωδικός (προαιρετικό)» φεύγει εντελώς. Δεν υπάρχει πια περίπτωση χειροκίνητου κωδικού — ο manager δεν τον βλέπει, δεν τον στέλνει, δεν τον θυμάται.
  • Το μήνυμα επιτυχίας δεν δείχνει ποτέ ξανά κωδικό. Λέει ότι στάλθηκε πρόσκληση, όχι «κράτησέ τον τώρα» — δεν υπάρχει πια τίποτα να κρατηθεί.
  • Ρητό μήνυμα όταν invited:false. Ποτέ σιωπηλή «επιτυχία» που θα άφηνε τον manager να νομίζει ότι έφυγε email ενώ δεν έφυγε — του λέει ακριβώς τι να κάνει αντ' αυτού (username + «Ξέχασα τον κωδικό»), ώστε το νέο μέλος να μπορεί να μπει έστω κι έτσι μέχρι να ρυθμιστεί το SMTP στην παραγωγή.
  • Καμία αλλαγή στα υπόλοιπα πεδία/ροή. Όνομα, email, ρόλος, το ίδιο κουμπί «Προσθήκη» — αλλάζει μόνο ό,τι αφορά τον κωδικό.
