Αποθήκευση: το κόψιμο γίνεται στη συσκευή και στον server πάει μόνο η τελική εικόνα 256×256 JPEG (≈20 KB). Ο server την ξανακάνει JPEG (σβήνει μεταδεδομένα, π.χ. τοποθεσία GPS της φωτογραφίας) και την κρατά στον προστατευμένο φάκελο αρχείων του CRM, όχι στη Βιβλιοθήκη Πολυμέσων του WordPress.
Ποιος τη βλέπει: μόνο συνδεδεμένοι χρήστες του CRM. Ο καθένας αλλάζει μόνο τη δική του. Η «Αφαίρεση» σβήνει το αρχείο. Όταν διαγράφεται ο χρήστης, σβήνεται κι αυτή.
PDF προσφοράς: η φωτογραφία μπαίνει στο «Σύμβουλος» μόνο αν τη θέλεις (διακόπτης στο προφίλ, κλειστός από προεπιλογή), για να μένει το PDF επίσημο.
Κλασική εμφάνιση: το avatar της δείχνει την ίδια φωτογραφία.
