Μετά την αλλαγή κωδικού

Από πίσω

• Κωδικός: ελέγχεται ο τωρινός (σωστός, αλλιώς μήνυμα· μετά από 5 λάθος σε 15′ κλειδώνει για λίγο). Ο νέος: ≥10 χαρακτήρες, όχι email/όνομα, όχι στη λίστα των πιο συνηθισμένων. Μετά: οι άλλες συνδέσεις κλείνουν, η τρέχουσα μένει. Καταγράφεται στο ιστορικό ασφαλείας (χωρίς τον κωδικό).

• Συνδέσεις: από τις συνδέσεις που κρατά ήδη το WordPress (ώρα σύνδεσης, browser/σύστημα, IP). Η IP φαίνεται μισή. «Αποσύνδεση» κλείνει τη μία· «από όλες τις άλλες» κρατά μόνο αυτή τη συσκευή.

• Νέα σημεία: POST /me/password, GET /me/sessions, DELETE /me/sessions/{id}, DELETE /me/sessions (όλες εκτός της τρέχουσας). Μόνο για τον ίδιο τον χρήστη.

• Η σύνδεση σε δύο βήματα μένει για επόμενο γύρο· η ενότητα είναι έτοιμη να τη δεχτεί.
